## Реализованный результат

Разработан API приёма событий безопасности на C# и ASP.NET Core (.NET 10).

- Приём имени сервера, источника и исходной строки журнала через `POST /api/events`.
- Проверка обязательных полей и ограничений длины; некорректный запрос отклоняется с кодом `400 Bad Request`.
- Автоматическое назначение событию уникального идентификатора `Guid` и времени получения в UTC.
- Формирование события `SecurityEvent` и возврат его в формате JSON.
- Получение учебного события через `GET /api/events/example`.

На текущем этапе событие возвращается в ответе без сохранения в базе данных.
